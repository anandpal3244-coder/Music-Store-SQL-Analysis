# 🎵 Music Store Data Analysis (SQL Project)

## 📌 Project Overview

This project analyzes a digital music store database using SQL to extract business insights.

## 🛠 Tools Used

* SQL
* PostgreSQL / MySQL
* Chinook Database

## 📊 Business Questions Solved

* Top spending customers
* Most popular music genre per country
* Customer purchase behavior
* Best-selling artists
* Revenue analysis

## 🔍 Key SQL Concepts Used

* JOINs
* GROUP BY
* Aggregations
* Window Functions (RANK, ROW_NUMBER)
* CTE (Common Table Expressions)

## 📈 Insights

* Identified highest revenue customers
* Found popular genres by country
* Determined top artists contributing to sales
